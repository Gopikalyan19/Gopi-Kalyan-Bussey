# Gopi Kalyan — Portfolio

Personal portfolio of Gopi Kalyan, UI/UX & Product Designer. Built with Next.js, React and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All copy (hero, services, projects, experience, skills, milestones) lives in `src/lib/content.ts`.
Images live in `public/` (projects, milestones, skill icons) and `src/assets/` (portrait).

## Build

```bash
npm run build
npm start
```

Deploys as-is to Vercel; the share image and site URL are picked up automatically.
